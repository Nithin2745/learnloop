# LearnLoop — Backend

Stateless Express API that turns a syllabus + exam date into a day-by-day
study plan with practice questions, generated by an LLM (Groq by default).

## Setup

```bash
cd backend
npm install
cp .env.example .env   # then edit .env and set GROQ_API_KEY
npm run dev            # starts on http://localhost:3001 (auto-reload)
```

## Environment

| Variable             | Default                     | Notes                                              |
| -------------------- | --------------------------- | -------------------------------------------------- |
| `LLM_PROVIDER`       | `groq`                      | `groq` or `openrouter`                             |
| `GROQ_API_KEY`       | —                           | required when provider is `groq`                   |
| `OPENROUTER_API_KEY` | —                           | required when provider is `openrouter`             |
| `LLM_MODEL`          | per-provider default        | override the model name                            |
| `LLM_BASE_URL`       | per-provider default        | override the base URL                              |
| `PORT`               | `3001`                      |                                                    |
| `CORS_ORIGIN`        | `http://localhost:5173`     | comma-separated allowed origins (the frontend)     |

### Failing over to OpenRouter

Set `LLM_PROVIDER=openrouter` and `OPENROUTER_API_KEY=...` — no code change.
The default OpenRouter model is `meta-llama/llama-3.3-70b-instruct`; override
with `LLM_MODEL` if you want a different one.

## Endpoints

### `GET /api/health`

```bash
curl http://localhost:3001/api/health
```

### `POST /api/generate-plan`

Request body:

```json
{
  "topics": "Calculus\nLinear Algebra (hard)\nProbability, Statistics",
  "examDate": "2026-10-15",
  "hoursPerDay": 3
}
```

Test with curl:

```bash
curl -s -X POST http://localhost:3001/api/generate-plan \
  -H "Content-Type: application/json" \
  -d '{"topics":"Calculus\nLinear Algebra (hard)\nProbability, Statistics","examDate":"2026-10-15","hoursPerDay":3}' | jq
```

Successful response (shape):

```json
{
  "totalDays": 0,
  "schedule": [
    {
      "date": "YYYY-MM-DD",
      "dayLabel": "Day 1",
      "topics": [
        { "name": "Calculus", "difficulty": "medium", "estimatedHours": 2 }
      ],
      "isBufferDay": false
    }
  ],
  "practiceQuestions": [
    { "topic": "Calculus", "questions": ["...", "...", "..."] }
  ]
}
```

### Error responses

| Status | When                                              |
| ------ | ------------------------------------------------- |
| `400`  | invalid input (empty topics, bad/past exam date)  |
| `429`  | LLM rate limited                                  |
| `500`  | server misconfigured (missing/invalid API key)    |
| `502`  | LLM call failed or returned unparseable output    |

All errors are JSON: `{ "error": "message", "details"?: [ ... ] }`.
